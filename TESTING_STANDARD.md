# Testing Standard

## Levels
1. Unit: isolated functions/components.
2. Integration: module, API, database or service interactions.
3. System: end-to-end behavior of the application.
4. UAT: user validates the actual outcome against acceptance criteria.

## Test dimensions as applicable
- Normal path.
- Empty/missing input.
- Invalid input.
- Error/failure path.
- Boundary conditions.
- Regression of related existing behavior.
- Security/permission behavior for sensitive operations.

## Evidence
Report command, outcome, and tests skipped. Do not fabricate results. Test data should be synthetic or approved and non-sensitive.

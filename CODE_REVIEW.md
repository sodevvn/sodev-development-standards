# Code Review Standard

Review the PR against the task and acceptance criteria.

## Checklist
- [ ] Requirements and acceptance criteria are met.
- [ ] Scope is limited; unrelated changes are absent.
- [ ] Logic and edge cases are addressed.
- [ ] Error handling and validation are appropriate.
- [ ] Security, permissions and sensitive data are considered.
- [ ] Database changes are safe, reversible where practical, and documented.
- [ ] Performance is reasonable for expected workload.
- [ ] Tests are meaningful and results are evidenced.
- [ ] Build/CI checks pass.
- [ ] Documentation/configuration updated as needed.
- [ ] No secrets or customer data exposed.

## Review outcomes
- APPROVED: ready to merge subject to branch rules.
- REQUEST CHANGES: blocking issues or missing evidence.
- COMMENT: non-blocking suggestions/questions.

AI review is advisory; authorized human approval is required.

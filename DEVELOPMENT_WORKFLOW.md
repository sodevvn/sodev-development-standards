# Development Workflow

## Issue states
- Backlog: captured, not prioritized.
- Ready: scoped and actionable.
- Analysis: agent investigates and plans.
- Plan Approved: required approvals received.
- In Progress: implementation underway.
- Testing: checks underway.
- Review: PR review underway.
- Blocked: dependency, decision, or failure blocks progress.
- Done: accepted, reviewed, and merged; release status tracked separately if needed.

## Task lifecycle
1. Create issue using template.
2. Confirm scope, priority and acceptance criteria.
3. Assign agent/human and establish task branch.
4. Agent posts plan; require approval for complex/risky tasks.
5. Implement and test.
6. Create PR referencing issue.
7. Review, resolve feedback, rerun checks.
8. Human approves and merges.
9. Update issue and release notes where applicable.

## Daily agent update
- Status
- Completed
- Next
- Blockers
- Files changed
- Checks and results

## Task sizing
Prefer tasks that can be implemented and reviewed independently. Split broad features into smaller tasks with clear outputs and dependencies.

# SODEV Software Architecture Principles

- Choose architecture based on product requirements and constraints, not fashion.
- Keep product repositories independently understandable and deployable where practical.
- Shared core modules should have explicit ownership, versioning and dependency boundaries.
- Avoid tightly coupling unrelated products.
- Document meaningful architectural decisions (context, options, decision, consequences).
- Local-first/hybrid deployment is a valid default for industrial data-sensitive use cases; cloud-first may suit pure SaaS.
- AI must not unilaterally change approved architecture.
